## 角色與視覺分析

固定五人：安安短髮髮夾、班長／常任主席；阿哲圓框眼鏡、講理記錄；小米雙辮安靜閱讀、常代表少數；浩浩刺短髮、喜歡運動與漫畫討論；林老師中長髮淺色襯衫、溫和提問不代替學生決定。

稿件要求台灣小學三年級、水彩手繪、柔線、淺藍或黃色制服、珊瑚／青綠／芥末點綴。三種框：思考小雷達珊瑚、社會小偵探青綠、知識便利貼芥末。八跨頁順序從發現問題→規畫執行→思考論證→檢討反思；課文上方、照片插畫漫畫對話下方，三張學習單置於跨頁2、5、8。

原稿圖片多為生成提示詞與排版預留位置，因此沒有將預留位置當成正式插畫。現階段自行製作 CSS 紙雕示意；第二階段才製作符合設定的正式素材。

## 轉化與界線

物件吸附、三格距離、結構式公約檢查、16／12選舉票、服務任務細節與新台詞都是數位原型自編規則；不宣稱為教材原文。六步驟不得加進「上次決議執行情形」成為第七步，該項在稿中明列教師手冊延伸。公開或私有網站均不打包翰林原文與圖片；本地抽取文字僅供分析且已 gitignore。
