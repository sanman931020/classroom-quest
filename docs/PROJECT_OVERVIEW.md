# 我們這一班 Classroom Quest

以三年級上學期社會第三單元「快樂的班級生活」為依據，讓學生在熟悉的閱讀角問題中練習自治、傾聽、共同決定與服務。第一階段交付可運行、可保存、可交接的技術原型；正式水彩美術不在本階段完成範圍。

只有三個主要活動：

1. 閱讀角改造計畫：探索五位角色的需要、分類問題、訂定公約、重新配置家具、觀察可解釋的模擬結果。
2. 班會大挑戰：認識幹部、四步驟選舉、會前提案、六步驟班會、發言佇列、教材示範表決、尊重少數與會議紀錄。
3. 校園服務特攻隊：選角色、探索四站、執行安全服務任務；完成任一站後記錄星期一到五的心情、觀察與建議。

三張成果為公約小檢查、我的提案單、一週行動回饋，皆在本機自動儲存並可匯出 JSON。活動可獨立進入，活動三未取得班會結果時提供明示的預設情境。

教師可投影共同操作，也可讓學生用橫向平板分組探究。不要以模擬通過視為真實班級已達成共識，亦不應把教材示範票數當成學生資料。
