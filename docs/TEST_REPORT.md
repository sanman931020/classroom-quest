## 修正與執行紀錄

初始npm網路DNS在沙箱內受限，經工具授權後安裝成功。初版Vitest3依賴含漏洞，更新修正版後重跑。首次E2E缺瀏覽器，下載Chromium後重試。發現5173屬其他專案，改專用5189且strictPort、不重用既有伺服器。測試角色定位改為容許無障礙名稱空白；拖曳前先將場景捲入畫面；截圖先等待首頁標題。觸控按鈕加入manipulation避免雙擊手勢干擾。班會最終紀錄保留臨時動議，並有E2E回歸。

## 未驗證與限制

觸控為Chromium hasTouch加CDP事件模擬，不是實際iPad；Safari、VoiceOver、讀屏完整性、真機效能與音訊尚未驗證。比例檢查確認無水平溢出，不能保證所有實機無遮擋；仍要人工逐項操作。未測多分頁同時寫存檔、惡意竄改存檔的全部組合、localStorage容量滿的真實裝置情境。沒有正式素材性能數據。服務四站規則都經單元測試，完整UI流程以衛生隊為代表。

自動化執行 `npm test` 與 `npm run test:e2e` 可重現；E2E自帶5189伺服器，用完停止。預覽使用5190以避免競爭。截圖在忽略追蹤的test-results，重跑會重建。
