# 核心玩法與完成條件

## 閱讀角改造計畫

點選安安、阿哲、小米、浩浩、林老師，解鎖各自的需要與「我可以怎麼幫忙」對話分支；再次點選回到原始線索。五人皆要聆聽。分類對應：安安／浩浩→公平使用、阿哲→環境整理、小米→聲音干擾、林老師→公約原則。

公約由「時間、適用對象、行動、照顧不同需要、自評可行」組成。明確檢查為時間非空、行動至少四字；公平為全班適用且勾選照顧需要；可行為學生自評勾選。這是結構檢查，沒有自然語言語意分析，不保證自由輸入的內容實際合理，教師仍須引導。

教室 8×4 格，家具各占一個邏輯格，最後一排通道禁止放置，禁止重疊與越界，釋放時四捨五入吸附。桌椅為一個群組物件。支援 Pointer 拖曳與「選家具→點空格」替代。失敗不改位置；重設回到有聲音衝突的起點。拖曳取消不提交。

模擬通過需：聽完五人、全部分類正確、公約三項通過、桌與墊中心格的歐氏距離至少三格。結果確定、可重試，五人依條件回饋。修改公約、分類或位置會取消舊完成旗標。此距離為自編教學模型，不是噪音物理模型。

## 班會大挑戰

五種幹部工作可閱讀。班長教學選舉依序：提名→附議並比較政見→舉手支持→宣布結果。本次演練任期為本次教學；候選為安安與阿哲，學習者可在比較後改支持另一人。示範以所支持人16、另一人12票，清楚標為模擬，非真實班級統計。

會前完成問題、提案、理由，並完成選舉，才能推進班會。正式程序：班會開始→主席報告→班長及各股股長報告→提案討論→臨時動議→散會（會後請導師指導）。點選非目前程序只提示、不跳步。

提案討論：附議後，邀請小米、浩浩、阿哲舉手加入 FIFO 佇列。主席同意一人，對方取得發言權；聽完才能同意下一人；重複申請不重複入列。聽完三人且無等待者／發言者時才開啟教材示範表決。固定方案安靜6、分區18、輪流4票，共28票。學習者提案獨立儲存，不會被誤加到教材票數。

分區通過後，寫至少四字的照顧少數做法，才可完成提案程序。臨時動議可輸入補充紀錄（非必填）；散會保存議題、提案、理由、示範決議、照顧少數做法與一週後檢討。重新演練會清除本次班會進度，不清除提案與選舉。

## 校園服務特攻隊

四站為同一活動內的服務地點，不另算四個活動。每站可隨時切換，答案依站與任務 ID 隔離。選擇四位學生之一扮演服務者。依場景把物品／意見送往合適位置並做安全判斷；目前是按鈕式任務原型，沒有實體搬運動畫。

衛生隊：紙張、空瓶分類與碎玻璃通報。交通隊：公平排隊、車輛靠近先退避通報。圖書隊：主題分類、核對歸還紀錄。學生自治會：整理反映需求、威脅事件陪同通知老師或家長。錯誤選項提供回饋並允許修正；所有任務正確且按完成才認證本站。修改為錯誤答案會取消該站完成。

任一站完成即開啟五天回饋：每天三種心情、自由觀察、全週改善建議。依實際試行逐日記錄，不強迫一次填滿。不依賴前兩活動，沒有班會紀錄時顯示預設分區試行約定。
