# AI小老師題庫

右下角「AI小老師」能回答的問題。學生打字或用說的提問後，在這台裝置上用關鍵詞與相似度找最接近的題目回答；不連網、不使用外部 AI 服務，也不保存對話。找不到時會推薦相關問題並請學生問老師；出現欺負、危險等字詞時，先請學生告訴老師或家長（113 保護專線／110）。

來源：**課本**＝依課本 p.5–12；**遊戲延伸**＝常見狀況的處理方式（可和老師、全班約定）；**操作**＝遊戲說明。修改題庫：`src/data/tutorQA.ts`，改完執行 `npx tsx scripts/dump-tutor-qa.ts` 更新本文件。

## 班會

| 問題 | 回答 | 來源 |
|---|---|---|
| 什麼是班會？ | 班會是全班一起開的會議。大家輪流說出想法，一起討論、一起決定班上的事情，讓班級生活更好。 | 課本 |
| 為什麼要開班會？ | 班上的事情是大家的事情。開班會可以讓每個人都有機會說話，聽聽不同的想法，再用公平的方法一起做決定。 | 課本 |
| 班會有哪些程序？ | 班會有六個程序：1. 班會開始　2. 主席報告　3. 班長及各股股長報告　4. 提案討論　5. 臨時動議　6. 散會（會後請導師指導）。 | 課本 |
| 主席、司儀、記錄要做什麼？ | 主席：負責主持班會進行。司儀：協助宣布班會程序。記錄：負責記錄會議的內容。 | 課本 |
| 主席要做什麼？ | 主席負責主持班會：請想發言的同學依順序說話、提醒大家不要離題，討論夠了再請大家表決。主席要公平，讓每個人都有機會說話。 | 課本 |
| 怎樣才是好主席？ | 好主席會：1. 公平的讓每個人輪流發言　2. 先聽完大家的意見　3. 提醒大家回到議題　4. 討論夠了才表決　5. 也照顧少數同學的想法。 | 遊戲延伸 |
| 主席可以說自己的意見嗎？ | 主席負責主持，要公平讓每個人發言。主席最好不要一開始就說出自己的答案，以免其他人不敢表達。 | 遊戲延伸 |
| 司儀要做什麼？ | 司儀協助宣布班會程序。依照六個程序的順序，一項一項清楚的宣布，例如「班會開始」「主席報告」，也可以提醒大家發言的規則。 | 課本 |
| 記錄要做什麼？ | 記錄負責記錄會議的內容：大家提出的意見、表決的結果，還有少數同學的意見。記得要寫得清楚、正確，不能只記自己贊成的。 | 課本 |
| 我是學生，開班會要做什麼？ | 學生也很重要！可以提出問題和提案，想說話先舉手，別人說話時專心聽，表決時用自己的想法舉手，最後也要遵守大家的決定。 | 課本 |
| 主席報告要說什麼？ | 主席報告時，可以說明今天班會要討論什麼，也可以說說上次班會決定的事情做得怎麼樣。 | 遊戲延伸 |
| 股長報告要說什麼？ | 班長和各股股長報告這段時間負責的工作，例如衛生股長說說整潔的情形，學藝股長說說布置和學習的事。 | 遊戲延伸 |
| 什麼是提案？ | 提案就是把你發現的班級問題，和你想到的解決方法寫下來，在班會中提出來請大家一起討論。提案應在會議前提出。 | 課本 |
| 提案要怎麼寫？ | 提案可以寫三個部分：1. 我發現的問題（例如：午休時閱讀角有聲音）2. 我的提案（例如：分成安靜區和討論區）3. 我的理由（例如：讓想安靜和想討論的人都有地方）。 | 遊戲延伸 |
| 什麼是臨時動議？ | 臨時動議是會議中臨時提出、事前沒有列入提案的新問題。可以簡單討論，重要的事可以下次班會再正式提案。 | 遊戲延伸 |
| 散會以後要做什麼？ | 散會後請導師指導。大家要照著班會的決定去做，過一段時間再一起檢查做得怎麼樣，需要的話下次班會再修改。 | 課本 |

## 選幹部

| 問題 | 回答 | 來源 |
|---|---|---|
| 什麼是任期？ | 任期是指擔任某項職務工作的時間期限。擔任幹部的時間由全班討論決定。 | 課本 |
| 選舉班級幹部有哪些步驟？ | 選舉班級幹部有四個步驟：步驟一：提名人選。步驟二：徵求附議，進行討論。步驟三：舉手表決。步驟四：宣布結果。 | 課本 |
| 提名要怎麼做？ | 提名時，說出你想推薦的人，還要說出理由，例如「我提名阿哲，因為他做事很仔細」。理由要和這個工作有關，不是因為他好笑或是你的好朋友。 | 遊戲延伸 |
| 可以提名自己嗎？ | 可以和老師、全班先約定好規則。如果可以，說說你為什麼想當、你會怎麼為大家服務，讓大家了解你的想法。 | 遊戲延伸 |
| 有人開玩笑亂提名怎麼辦？ | 主席可以請提名的人說說理由：「他哪裡適合為大家服務？」說不出和工作有關的理由，就不是認真的提名。被提名的同學也可以說不想當。 | 遊戲延伸 |
| 什麼是附議？ | 附議表示一個人以上贊成這個提議，以舉手或口頭表達。 | 課本 |
| 沒有人附議怎麼辦？ | 沒有人附議，表示目前沒有其他人贊成，這個提名或提案就先不討論。可以修改想法，下次再提出。 | 遊戲延伸 |
| 選幹部時要討論什麼？ | 可以請候選人說說「我會怎麼為大家服務」，大家也可以說說誰比較適合這個工作，比一比他們的想法。 | 遊戲延伸 |
| 班上有哪些幹部？要做什麼？ | 班長：統整幹部工作、協助班務。衛生股長：協助整潔工作。學藝股長：協助學習與布置。體育股長：協助器材借還。風紀股長：溫和提醒秩序。 | 遊戲延伸 |
| 班長要做什麼？ | 班長統整幹部的工作、協助班上的事務，常常也是班會的主席。班長不是比較大，而是要為大家服務。 | 遊戲延伸 |
| 怎樣的人適合當幹部？ | 想一想這個工作需要什麼，例如細心、負責、願意幫忙。選願意為大家服務、也做得到的人，不是只選好朋友或最受歡迎的人。 | 遊戲延伸 |
| 沒有當選怎麼辦？ | 沒有當選不是輸。班上同學都有機會擔任幹部；也可以用其他方式為大家服務。 | 課本 |
| 當選以後要做什麼？ | 謝謝大家的支持，然後認真做好工作、為大家服務。也可以謝謝其他候選人，大家一起讓班級更好。 | 遊戲延伸 |

## 發言與討論

| 問題 | 回答 | 來源 |
|---|---|---|
| 想發言時要怎麼做？ | 發言時要先舉手，並經主席同意才能發言；他人發言時，要專心聆聽，尊重同學的意見。 | 課本 |
| 很多人舉手，誰先說？ | 主席依照舉手的先後順序，一個一個請同學發言。先舉手的先說，大家輪流，每個人都有機會。 | 遊戲延伸 |
| 別人說話時要怎麼做？ | 眼睛看著說話的人、專心聽完，不插嘴、不笑別人。就算不同意，也要先聽完，再舉手說出你的想法。 | 課本 |
| 怎麼把理由說清楚？ | 可以用這個句子：「我支持（什麼方案），因為（理由）。」理由最好說出會讓大家變得更好的地方，例如「這樣想安靜的人也有地方」。 | 遊戲延伸 |
| 我不同意別人的想法怎麼辦？ | 等他說完，再舉手說：「我有不同的想法，因為……」。要對事不對人，說想法哪裡不好，不說人不好。 | 遊戲延伸 |
| 什麼是對事不對人？ | 對事不對人，就是討論「這個方法好不好」，不是說「這個人好不好」。例如說「這個方法會太吵」，不要說「你很煩」。 | 遊戲延伸 |
| 我不敢在班會說話怎麼辦？ | 沒關係！可以先把想說的話寫在紙上，用「我覺得……，因為……」來說。說錯也沒關係，班會就是讓大家練習說出想法的地方。也可以先告訴老師或好朋友。 | 遊戲延伸 |
| 有同學一直都沒說話怎麼辦？ | 主席可以溫和的邀請：「還有沒有人想說說看？」也可以問問比較安靜的同學有沒有想法，但不要勉強他。 | 遊戲延伸 |
| 討論離題了怎麼辦？ | 主席提醒大家回到今天的議題；新的問題可以在「臨時動議」提出，或下次班會再提案。 | 遊戲延伸 |
| 有人插話、起鬨怎麼辦？ | 主席或司儀可以有禮貌地提醒：先舉手，等正在發言的同學說完，再請下一位。 | 遊戲延伸 |
| 班會太吵怎麼辦？ | 主席可以請司儀提醒大家坐好、安靜下來，等大家都聽得到再繼續。大家一起遵守「先舉手再發言」，班會就會比較順利。 | 遊戲延伸 |

## 表決

| 問題 | 回答 | 來源 |
|---|---|---|
| 什麼時候可以表決？ | 提案應在會議前提出，並在會議中充分討論。當討論意見已充分表達時，主席可以請大家進行表決。 | 課本 |
| 表決有哪些方式？ | 常見的表決方式有：舉手表決、起立表決、投票表決。 | 課本 |
| 什麼是服從多數、尊重少數？ | 表決後，要照著多數人的決定去做，這是服從多數；也要聽聽少數同學的想法、照顧他們的需要，這是尊重少數。 | 課本 |
| 表決後少數人不滿意怎麼辦？ | 要確實遵守表決通過的事項，並尊重少數人的意見；也可以問問少數同學有什麼困難，一起想辦法。 | 課本 |
| 我投反對，也要遵守決定嗎？ | 要喔！表決通過的事，大家都要確實遵守，班級才會有秩序。如果試了一段時間發現有問題，可以在下次班會提出來，大家再討論修改。 | 課本 |
| 如果平票怎麼辦？ | 可以請候選人或提案人再說明一次，大家再討論、再表決。如果還是平票，由全班事先約定公平的方法（例如抽籤），並請老師協助。不由主席一個人決定。 | 遊戲延伸 |
| 有人重複舉手或沒舉手怎麼辦？ | 提醒「每個人只能舉手一次」，必要時重新再數一次，讓票數正確。 | 遊戲延伸 |
| 可以跟著好朋友一起舉手嗎？ | 表決要用自己的想法決定。想一想哪個方法對全班比較好，再舉手。不用因為好朋友選什麼就跟著選。 | 遊戲延伸 |
| 6／18／4 是什麼票數？ | 這是課本的示範表決：閱讀角三個方案，A 安靜 6 票、B 分區 18 票、C 輪流 4 票，所以通過「分成安靜區和討論區」。遊戲裡的票數是固定的示範，不是同學真的投的票。 | 課本 |

## 狀況處理

| 問題 | 回答 | 來源 |
|---|---|---|
| 有人在班會笑我、罵我怎麼辦？ | 這樣不對，你沒有錯。請馬上告訴老師或家長，讓大人幫忙。班會要對事不對人，每個人都應該被尊重。 | 遊戲延伸 |
| 有人不遵守班會的決定怎麼辦？ | 可以先溫和的提醒他，說明這是大家一起決定的事。如果一直不遵守，可以請幹部或老師協助，也可以在下次班會提出來討論。 | 遊戲延伸 |
| 決定好的事可以改嗎？ | 可以。先照著決定試一段時間，觀察做得怎麼樣；發現問題，就在下次班會提出來，大家再討論、再表決。 | 遊戲延伸 |
| 班會時老師要做什麼？ | 班會由同學們主持，老師在旁邊觀察。散會時請導師指導，遇到吵架、不公平或不安全的事，也可以請老師協助。 | 課本 |
| 閱讀角的問題可以怎麼解決？ | 可以先找出問題（太吵、書沒放回去），再想方法，例如分成安靜區和討論區、看完把書放回原位。大家討論、表決後，一起照著做，一週後再檢查。 | 遊戲延伸 |

## 遊戲操作

| 問題 | 回答 | 來源 |
|---|---|---|
| 這個遊戲怎麼玩？ | 先選討論主題（選舉班級幹部或班會提案），再選你的角色（主席、司儀、記錄或學生）。對話框出現時，點一個你覺得好的做法，再看看這個決定帶來什麼影響。 | 操作 |
| 選不同角色有什麼不一樣？ | 每個角色會遇到不一樣的狀況，要做的決定也不同。玩完一次後，可以換一個角色，看看別人在班會中會遇到什麼事。 | 操作 |
| 上面的三條儀表是什麼？ | 三條儀表是「會議秩序」「公平公正」「大家被聽見」。你做的決定會讓它們變高或變低，同學的表情也會跟著改變。 | 操作 |
| 選錯了怎麼辦？ | 不會失敗喔！選了不好的做法，會看到可能發生的影響。到「反思」的「如果重來」，可以看看更好的做法，也可以重新演練。 | 操作 |
| 論點卡是什麼？ | 同學發言後，你會收到他的論點卡，上面寫著他支持什麼方案、理由是什麼。點卡片可以再看一次，幫助你比較不同的想法。 | 操作 |
| 「影響」頁在看什麼？ | 「影響」會模擬做完決定後一週的情形。笑臉越多，表示這個決定讓班級越順利。這是遊戲模擬，可以想想真的班級會不會這樣。 | 操作 |
| 小百科和小短片在哪裡？ | 右上角的「小百科」有班會的正式流程和常見狀況；「小短片」在首頁和小百科裡，有選幹部、開班會、服從多數尊重少數三部。 | 操作 |
| 怎麼關掉聲音或朗讀？ | 按右上角的「聲音開／關」可以關掉全部聲音；按暫停 → 設定，可以單獨關掉朗讀或背景音樂。 | 操作 |
| 注音可以關掉嗎？ | 可以。按暫停 → 設定，把「注音」關掉就好。 | 操作 |
| 進度會不見嗎？ | 不會，進度會自動存在這台裝置裡。下次打開按「繼續」就可以接著玩。 | 操作 |
| 怎麼用說的問AI小老師？ | 按輸入框旁邊的麥克風，說出你的問題，說完會自動變成文字，再按「送出」就好。 | 操作 |
