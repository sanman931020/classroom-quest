# 開發現況

## 已完成的互動核心

- React/TypeScript/Vite可啟動、靜態建置、首頁三入口、共用場景切換、進度旗標。
- 五角色點擊、需要線索與追問分支、問題分類、公約輸入與三項結構檢查。
- 三個家具群組滑鼠／觸控Pointer拖曳、吸附、拒絕重疊／越界／通道、點選替代、重設與位置儲存。
- 確定性公約／空間模擬與五角色條件回饋，修改後重試。
- 幹部職責、四步驟教學選舉、正式六步驟班會、會前提案、附議、FIFO發言權、聽完才表決、教材固定票數、照顧少數與決議／臨時動議保存。
- 四服務站與角色選擇、各站規範及安全判斷、任一站完成開啟五日回饋、無前置關卡也能使用預設情境。
- 三張成果輸入、自動localStorage保存、重整恢復、基本損毀驗證、儲存失敗提示、JSON匯出。
- 平板響應式、aria-live操作提示、鍵盤可點按鈕與格子、降低動畫偏好。
- 核心單元測試、Chromium端對端流程、觸控模擬與兩平板比例檢查；完整技術／教材／交接文件。

## 部分完成與原型限制

- 2.5D僅首頁紙雕示意；互動教室為邏輯格點，校園為簡化地圖，未完成正式等角美術。
- 角色是CSS簡化圖，不是最終水彩素材；過渡效果基本，無完整角色動作。
- 服務任務以按鈕將物品或需求送到選定分類／管道，未製作拖曳搬運、借還動畫。
- 公約檢查只驗證欄位、適用對象與勾選自評；不是語意判斷或實際公平性評量。
- 選舉16／12與班會6／18／4皆為教學示範，不收集實際班級選票。
- DOM/CSS + React狀態，沒有PixiJS、GSAP、Tailwind、IndexedDB，原需求列為建議工具；資料模型小，選localStorage維持靜態可攜。
